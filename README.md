# minimalist-portfolio-json

Portfolio web con Astro.

## Instalación

```sh
git clone https://github.com/xSergioBG/minimalist-portfolio-json.git
cd minimalist-portfolio-json
npm ci
npm run dev
```

Consulta `package.json` y el lockfile para las versiones del proyecto. La compatibilidad de estas dependencias debe comprobarse antes de migrarlas.

## Scripts declarados

| Comando | Implementación |
| --- | --- |
| `npm run dev` | `astro dev` |
| `npm run start` | `astro dev` |
| `npm run build` | `astro check && astro build` |
| `npm run preview` | `astro preview` |
| `npm run astro` | `astro` |
